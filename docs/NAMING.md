# Naming

**Artha (अर्थ)** — one of the four *puruṣārthas* in classical Hindu philosophy
(dharma, artha, kāma, mokṣa), specifically denoting wealth, material
prosperity, and the practical means of livelihood. It's the traditional
Sanskrit frame for "the economic/financial dimension of life," which maps
directly onto what this tool does (markets, portfolios, macro data, research)
— and it doubles as a clean, short Rust crate/binary prefix.

Binary name: `artha`
Crate prefix: `artha-*` (e.g. `artha-core`, `artha-tui`)

If a closer homage to the source inspiration is wanted later, **Arthashastra**
(अर्थशास्त्र, "the science of wealth/statecraft" — Kautilya's classical
treatise on economics and governance) is the natural fuller-form alternative,
but it's long for a binary/crate prefix, so `artha` is used as the working
name throughout this workspace.
